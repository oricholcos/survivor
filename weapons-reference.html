全局规则与通用牌

  • 成长模型：武器 0 级起步、以 base 数值作战；每吃一张牌 level+1（0~10 封顶）。没有「每级自动成长」，全部数值与机制成长由牌注入。拥有全部 4 栏武器且全部满级后解锁无限牌池（数量上限失效、一次性牌仍限一次，hardMax 硬上限例外永远生效）。
  • 数值契约：数值全部来自武器 JSON 数据表；仅几何量（弹丸半径、错开角等）允许硬编码。
  • 确定性：行为零随机（目标选择、计数推进、扇形分布全为确定性映射），同种子全程可复现。唯一战斗期随机是蓄能狙击【爆头】掷点，走独立第二随机流（种子 = 会话种子 XOR 0x9E3779B9 的固定 LCG），绝不消费主随机流——升级三选一 / 开局武器抽取等主随机流序列零扰动。
  • 统一四级优先级：① Boss（多个取最近）→ ② 贴墙攻击怪（正在打墙的最高威胁层）→ ③ 快速怪（speed ≥ 阈值，取最近）→ ④ 最近敌人；同级取最近、平距取数组先。完整四级（Boss+快速偏好）：蓄能狙击、灼热光束（粘性锁定例外：四级只在首次锁定与死亡重选时生效——目标存活期间出程也照打）；默认档（贴墙 > 最近）：轨道贯穿炮、弹射棱镜；追猎导弹为自实现选择（始终锁定最近敌人，无贴墙层）；扇面霰弹 / 迫击榴弹 / 震波壁垒无索敌。
  • 无目标不开火且冷却归 0：全部 8 把（霰弹 = 有效射程内无怪、震波壁垒 = 行进波可达范围（220+40=260px）内无存活敌人、其余 = 索敌无目标；灼热光束为粘性锁定例外——绑定目标存活但出程不算无目标，照常开火）。冷却归 0 是「本帧重试」标记，解释器据此区分空转与真实开火——协同齐射的「空转恢复冷却」也依赖该约定。
  • 移动预测（leadAim）：弹道武器开火瞬间按目标当前速度解二次方程提前量（预测点钳到墙线，贴墙/眩晕目标速度按 0）——蓄能狙击主弹、弹射棱镜首跳、迫击榴弹落点、分裂/多射次级弹初速；弹射棱镜的后续弹跳与追猎导弹的逐帧追踪不加预测。轨道贯穿炮为 hitscan（零飞行时间）无提前量。
  • 协同开火（灼热光束专属牌驱动，机制详见⑦）：任一目标协同计数 ≥ 30 → 以该目标为对象驱动其他所有已拥有武器齐射一次——狙击 / 棱镜 / 导弹 / 榴弹 / 贯穿炮强制锁定该目标走真实开火流程（斩首/爆头/死刑宣告/弹跳/AoE 等判定照常），霰弹（目标在有效射程内）与震波壁垒（目标在行进波可达范围内）按各自正常逻辑发动；齐射不影响被触发武器的冷却节奏。
  • 连射重放：跟发波到点重放时重新执行该武器的目标选择 / 密度选点（不是简单复制品），无目标波静默跳过。

全武器唯一的全宽度行进波防线节拍器：波前从墙线出发向上行进，经过谁结算谁（伤害 + 击退 + 眩晕）；无索敌、无弹道、零随机

索敌逻辑

判定范围无索敌：线性扫描全部存活敌人。开火门槛 = 行进波可达范围内（|y − 墙线| ≤ 行进距离 + 波前厚度，基础 220+40=260px，全 x 宽度、无数量上限）存在存活敌人；无可达目标 → 不开火、冷却归 0（可达但波前尚未经过的目标算可达——门槛按最终范围判定）。
行进波几何开火 = 从墙线发出一道横贯全屏的扫掠波：波前位置 = 墙线 − 行进距离 ×（已扫时间 ÷ 400ms），向 y 减小方向推进；扫掠总时长恒为 400ms（几何常量，不随距离变化——范围强化提高的是波前速度与最终距离）。波前判定带宽 = |y − 波前| ≤ 波前厚度（基础 40px，恰在边界算在内）；逐帧按「上一帧带 ∪ 本帧带」走廊结算（任意帧步长零漏判），每敌每次行进波至多结算一次（被击退向上重入波前区不重复掉血）。
结算顺序波前经过时按数组序逐个：伤害 →（幸存者）击退（效果引擎强制竖直向上 = 推离墙线，冲量 110；按怪物类型抗性固定）→（幸存者）眩晕（800ms，Boss 减半为 400ms）。致死一击不附着 CC。波在墙线出生的瞬间即结算贴墙带（≤40px）。
过载共振结算时已处于眩晕中的目标伤害 ×2——判定时刻 = 波前经过该敌人的那一刻：本波自己挂的眩晕不影响本波对该敌人的判定（每敌每波只结算一次），下一波波前再经过时才吃到 ×2（余震结算时仍眩晕的目标同样 ×2）。
城垣共鸣按整次行进波的累计命中数（从发出到扫完，含被本波击杀者；余震不计数）在波扫完时（400ms）一次性判定 ≥8 → 回复墙血。
